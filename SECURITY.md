# Security Policy

## Supported Versions

Only the latest version of the `master` branch is currently supported.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting feature from the Security tab.

Include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested remediation, if available

Please do not include real API keys, credentials, or sensitive production data.
